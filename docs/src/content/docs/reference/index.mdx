Precise, lookup-oriented pages that the task-based guides link into. Each page
is a flat reference for one part of docmeta: commands, config keys, resolution
rules, formats, output, and the built-in schemas. Use the table of contents on
each page to jump to the exact entry you need.

Looking for what ships in the box? [**Built-in
schemas**](/docmeta/reference/built-in-schemas/) is the registry: all twenty-one in
one table, with what each constrains and which two are on by default.
